# Dhruv Patel — Portfolio

An original, responsive portfolio for my work and interests in cybersecurity,
systems, and automation. Built with React, TypeScript, Vite, and CSS.

## Run locally

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

The production site is generated in `dist/`. No environment variables are
required.

## Portfolio content

- Security operations, blue-team experience, and technical skills
- Car Reliability Analyzer live demo
- Hojaiga.com AI automation project in development
- Résumé PDF and contact links

The résumé PDF in `public/` is provided for the portfolio owner.
